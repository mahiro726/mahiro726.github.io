项目成果

参照 tcmalloc 思路实现三级缓存内存池，公开仓库包含分配与回收代码、测试及基准程序。

技术亮点

  • ThreadCache：线程本地缓存与小对象复用。
  • CentralCache：共享对象管理、桶锁与批量调拨。
  • PageCache：连续页与 Span 管理。

实践重点

通过学习实现，将内存管理、线程同步与资源复用落实到代码，关注缓存占用和同步开销之间的取舍。
